# SEO roadmap

## Phase 1 — Research

Validate supplied keyword research, search intent, audience needs and SERP patterns. Retailer pages are competitors; the content gap is a comparison-first experience.

## Phase 2 — Website architecture

Maintain clean category, capacity, guide and product-comparison URLs. Keep keyword-to-page ownership explicit in `SEO-MAPPING.md`.

## Phase 3 — Technical SEO

Set `VITE_SITE_URL`, generate production sitemap URLs, verify robots, canonicals, titles, descriptions, Open Graph image and structured data. Consider prerendering/SSR for production discovery.

## Phase 4 — Content

Expand original buying guides, DDR4 vs DDR5 comparisons and capacity pages using verified specifications. Avoid keyword stuffing and thin duplicates.

## Phase 5 — Backlinks

Create linkable original resources such as a RAM Price Guide India. Seek legitimate instructor-approved or editorial mentions only; never manufacture backlinks or use spam networks.

## Phase 6 — Analytics

Add consent-appropriate analytics, Search Console, conversion events for outbound clicks and tracking for search/filter use after launch.

## Phase 7 — Audit

Periodically audit indexability, mobile UX, Core Web Vitals, broken outbound links, structured data and stale product-price records.
